# LinguaWorld — 多语种在线学习平台

## 1. 产品概述

LinguaWorld 是一款沉浸式多语种在线教育平台，支持英语、日语、韩语等主流语言的学习。平台通过互动式学习模块、个性化路径推荐和成就激励系统，为用户打造如同置身语言环境的学习体验。

### 目标用户
- 语言学习初学者至中高级学习者
- 希望提升职场竞争力的职场人士
- 对异国文化感兴趣的兴趣学习者
- 准备留学/移民的语言备考者

### 核心价值
- 沉浸式学习体验，告别传统枯燥记忆
- AI 驱动的个性化学习路径
- 完整的进度追踪与成就激励

## 2. 核心功能模块

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 游客 | 无需注册 | 浏览公开课程、体验demo |
| 注册用户 | 邮箱/手机注册 | 完整学习、社区互动、进度追踪 |
| 会员用户 | 付费升级 | 高级课程、AI口语陪练、离线学习 |

### 2.2 功能模块清单

#### 2.2.1 用户认证模块
- **注册页面**：邮箱/手机号注册，支持密码强度验证
- **登录页面**：邮箱/手机号 + 密码登录，支持记住登录状态
- **个人中心**：头像、昵称、学习目标设置

#### 2.2.2 语言选择与课程体系
- **语言切换器**：支持英语、日语、韩语快速切换
- **分级课程**：CEFR 标准（A1-C2）六个级别
- **课程卡片**：语言、级别、课程数、预计时长、难度标签

#### 2.2.3 互动式学习模块
- **单词记忆**：闪卡翻转、艾宾浩斯记忆曲线、智能复习
- **语法练习**：填空题、选择题、错误句子纠正
- **口语跟读**：录音对比、波形可视化、发音评分
- **听力训练**：场景对话、新闻听力、速度调节

#### 2.2.4 学习进度追踪
- **学习仪表盘**：今日学习时长、本周学习天数、连续学习记录
- **进度环形图**：各模块完成百分比
- **学习日历**：每日学习打卡可视化
- **能力雷达图**：词汇、语法、口语、听力四维能力展示

#### 2.2.5 个性化学习路径
- **水平测试**：入学测试确定初始等级
- **智能推荐**：根据学习数据推荐下一节课
- **薄弱点强化**：自动识别并推送相关练习

#### 2.2.6 社区交流系统
- **学习小组**：按语言/等级创建学习小组
- **话题讨论**：发起话题、回复讨论
- **学习圈动态**：分享学习心得、每日打卡

#### 2.2.7 成就激励系统
- **成就徽章**：首次登录、学习里程碑、技能解锁
- **排行榜**：日榜、周榜、好友榜
- **学习奖励**：连续学习天数徽章、完课证书

## 3. 核心用户流程

### 3.1 新用户首次体验流程

```
访问首页
  ↓
选择学习语言（英语/日语/韩语）
  ↓
完成入学水平测试（可选跳过）
  ↓
系统推荐适合的课程级别
  ↓
开始第一节免费课程
  ↓
注册账号保存学习进度
```

### 3.2 每日学习流程

```
打开应用 → 今日学习提醒
  ↓
进入学习模块（单词/语法/口语/听力）
  ↓
完成学习任务 + 获取经验值
  ↓
查看进度更新 + 获得成就
  ↓
浏览社区动态 / 发起讨论
  ↓
明日学习目标预告
```

## 4. 页面设计规范

### 4.1 设计风格

**主题定位**：现代学院风 — 融合学术严谨与现代活力

**配色方案**：
- 主色：深靛蓝 `#1e3a5f`（传递专业与信任）
- 辅色：暖金色 `#f4a261`（活力与成就感）
- 强调色：薄荷绿 `#2ec4b6`（学习的清新感）
- 背景色：米白 `#faf8f5` + 浅灰蓝 `#e8f4f8`
- 文字色：深灰 `#2d3436` / 浅灰 `#636e72`

**字体选择**：
- 标题：`Noto Serif SC`（优雅学术感）
- 正文：`Noto Sans SC`（清晰易读）
- 数字/数据：`DM Sans`（现代简洁）

**按钮样式**：圆角胶囊形，hover 时轻微上浮 + 阴影加深

**图标风格**：线性图标，统一 1.5px 线宽，柔和圆角

**布局风格**：卡片式布局，留白充足，模块化设计

### 4.2 页面结构总览

| 页面名称 | 核心模块 | 主要交互 |
|----------|----------|----------|
| 首页 | Hero区、语言选择、精选课程、学习数据概览 | 语言切换、课程卡片点击 |
| 学习页 | 单词卡、语法练习、口语录音、听力播放器 | 翻转、点击、拖拽、录音 |
| 进度页 | 环形图、日历、雷达图、成就墙 | 数据可视化、日期筛选 |
| 社区页 | 话题列表、发帖、回复、点赞 | 列表滑动、富文本编辑 |
| 个人中心 | 头像信息、学习设置、会员管理 | 表单编辑、设置切换 |
| 登录/注册 | 表单、验证码、第三方登录 | 表单验证、跳转 |

### 4.3 响应式策略

- **桌面优先**（1280px+）：三栏布局，左侧导航 + 主内容 + 侧边栏
- **平板适配**（768px-1279px）：双栏布局，折叠导航
- **移动适配**（< 768px）：单栏布局，底部 Tab 导航

## 5. 技术需求（非功能性）

### 5.1 性能要求
- 首屏加载时间 < 3秒
- 页面切换动画流畅（60fps）
- 音频/视频播放无卡顿

### 5.2 可访问性
- 支持键盘导航
- 图片 Alt 标签完整
- 颜色对比度符合 WCAG 2.1 AA 标准

### 5.3 数据安全
- 用户密码加密存储（bcrypt）
- 敏感操作需二次验证
- 学习数据定期备份
